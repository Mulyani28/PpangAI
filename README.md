
# Ppang - AI-Powered Carbon Footprint Tracker

An intelligent sustainability application that leverages machine learning to track environmental metrics and provide personalized insights for waste management and carbon footprint reduction.

## 🎯 Key Features

- **AI-Powered Insights**: Get personalized recommendations and analysis of your emission patterns
- **Interactive Dashboard**: Visualize your carbon footprint with dynamic charts
- **ML-Based Predictions**: Advanced forecasting of future emissions
- **Smart Recommendations**: Receive tailored suggestions to reduce your environmental impact

## 📊 Dashboard & Analytics

The dashboard provides comprehensive visualizations of your:
- Daily and monthly emission trends
- Category-wise breakdown
- Sustainability score
- Waste management metrics

## 🤖 AI Features

- Pattern recognition in emission data
- Anomaly detection
- Trend analysis
- Personalized recommendations
- Future emission predictions

## 🔍 Categories Tracked

- 🚗 Transport emissions
- ⚡ Energy consumption
- 🍽️ Food-related emissions
- ♻️ Waste management

## 💻 Technology Stack

- **Backend**: Python Flask
- **Database**: SQLite with SQLAlchemy
- **ML/AI**: scikit-learn
- **Visualization**: Plotly
- **Frontend**: HTML, CSS, JavaScript

## 🚀 Getting Started

1. Click the "Run" button to start the Flask server
2. Create an account or log in
3. Start tracking your emissions through the Data Entry page
4. View your personalized dashboard and AI insights

## 📱 Features in Detail

### Data Entry
Easy-to-use forms for logging:
- Transport activities
- Energy consumption
- Food choices
- Waste disposal

### AI Insights
- Pattern recognition
- Anomaly detection
- Trend analysis
- Sustainability scoring

### Predictions
- ML-based emission forecasting
- Multiple reduction scenarios
- Customizable prediction timeframes

## 🔒 Data Privacy

All data is stored securely in a local SQLite database. User information and emission data are kept private and used only for generating personalized insights.
